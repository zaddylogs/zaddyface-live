# ZaddyFace Live

ZaddyFace Live is a secure, ethical AI face-swap video calling platform. It is designed for entertainment, creative expression, and real-time communication while enforcing consent-driven use, privacy protections, moderation, and clear disclosure.

## Overview

ZaddyFace Live allows users to join live calls, apply AI face-swap and visual effects, and manage communication with secure controls. The platform is built around consent, transparency, safety, and respect for identity rights.

## Features

- Real-time AI face-swap during live calls
- Secure registration and login
- Camera and microphone permission controls
- Live video calling between consenting participants
- Face filters and customizable visual effects
- Clear live disclosure when AI face-swap is active
- Consent verification before facial image use
- Privacy-first handling of face data
- Reporting and blocking tools
- Admin moderation dashboard

## Safety commitments

- Only authorized and consenting participants can enable AI effects
- No unauthorized use of another person’s face or identity
- No impersonation of public figures or private individuals
- No support for fraud, scams, or deceptive identity presentation
- Instant disable option for face-swap effects
- No recording or storage of calls without explicit consent

## Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Real-time communication: WebRTC, LiveKit, Mediasoup
- Backend: Node.js, NestJS
- Database: PostgreSQL
- Cache/session: Redis
- AI processing: Python, FastAPI, OpenCV, MediaPipe, InsightFace
- Deployment: Docker, cloud infrastructure, GPU support
